## `cva`

Builds a `cva` component

```ts
import { cva } from "cva";

const component = cva(options);
```

### Parameters

1. `options`
   - `base`: the base class name (`string`, `string[]` or other [`clsx` value](https://github.com/lukeed/clsx#input))
   - `variants`: your variants schema
   - `compoundVariants`: variants based on a combination of previously defined variants
   - `defaultVariants`: set default values for previously defined variants.
   - `composes`: shallow merge one or more other `cva` components into this one — a single component, or an array. See [Composing Components](/getting-started/composing-components).

### Returns

A `cva` component function

## `cx`

Concatenates class names (an alias of [`clsx`](https://github.com/lukeed/clsx))

```ts
import { cx } from "cva";

const className = cx(classes);
```

### Parameters

- `classes`: array of classes to be concatenated ([see `clsx` usage](https://github.com/lukeed/clsx#input))

### Returns

`string`

## `compose`

:::caution
**Deprecated** — use the [`composes` key](#cva) inside `cva` instead. See [Composing Components](/getting-started/composing-components) for migration examples.
:::

Shallow merges any number of `cva` components into a single component.

```ts
import { compose } from "cva";

const composedComponent = compose(options);
```

### Parameters

`options`: array of `cva` components

### Returns

A `cva` component function

## `getSchema`

Extracts a plain-object schema — variant names, their possible values, and default values — from a `cva` component. Useful for generating Storybook controls/args, documentation, or any other UI that needs to introspect a component's variants without re-declaring them.

```ts
import { cva, getSchema } from "cva";

const button = cva({
  base: "button",
  variants: {
    intent: {
      primary: "button--primary",
      secondary: "button--secondary",
    },
    disabled: {
      true: "button--disabled",
      false: "button--enabled",
    },
  },
  defaultVariants: {
    intent: "primary",
    disabled: false,
  },
});

getSchema(button);
// => {
//   intent: { values: ["primary", "secondary"], defaultValue: "primary" },
//   disabled: { values: [true, false], defaultValue: false },
// }
```

A variant is omitted from the result if it has no values (e.g. `variants: { empty: {} }`).

### Parameters

`component`: a component created by `cva` (including components composed via [`composes`](#cva))

### Returns

An object keyed by variant name. Each entry has:

- `values`: a readonly array of the variant's possible values
- `defaultValue`: present only if the variant has a `defaultVariants` entry

## `defineConfig`

Generate `cva`, `cx` and `compose` functions based on your preferred configuration.

Store in a `cva.config.ts` file, and import across your project.

```ts
// cva.config.ts
import { defineConfig } from "cva";

export const { cva, cx, compose } = defineConfig(options);
```

1. `options`
   - `hooks`
     - `onComplete`: returns a concatenated class string of all classes passed to `cx`, `cva` or `compose`.
