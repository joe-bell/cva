## Merging Tailwind classes

This example follows shadcn/ui's popular [`cn` helper](https://ui.shadcn.com/docs/installation/manual#add-a-cn-helper): `clsx` resolves `cva`'s authoring grammar and [`tailwind-merge`](https://github.com/dcastil/tailwind-merge) dedupes conflicting Tailwind utilities. It's wired in as `cva`'s concatenator via [`cva/core`](/beta/api-reference#cvacore) and re-exported as `cn` for parity. See [Handling style conflicts](/beta/getting-started/installation#handling-style-conflicts) for the details.

## Merging Tailwind classes with cn

The published [`cn`](https://github.com/shadcn-ui/cn) package bundles `clsx` and `tailwind-merge`, and its input type matches `cva`'s. Configure [`cva/core`](/beta/api-reference#cvacore) with `defineConfig({ cx: cn })` to preserve object and array authoring, then re-export `cx` as `cn`; see [Handling style conflicts](/beta/getting-started/installation#handling-style-conflicts) for details.
