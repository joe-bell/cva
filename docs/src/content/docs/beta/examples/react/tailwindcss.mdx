## Merging Tailwind classes with tailwind-merge

This example composes [`clsx`](https://github.com/lukeed/clsx), which resolves `cva`'s authoring grammar, with [`tailwind-merge`](https://github.com/dcastil/tailwind-merge), which dedupes conflicting Tailwind utilities. This is the pattern behind shadcn/ui's [`cn` helper](https://ui.shadcn.com/docs/installation/manual#add-a-cn-helper). It's wired in as `cva`'s concatenator via [`cva/core`](/beta/api-reference#cvacore) and re-exported as `cn`. See [Handling style conflicts](/beta/getting-started/installation#handling-style-conflicts) for the details.

## Merging Tailwind classes with cn

This example uses the [`cn`](https://github.com/shadcn-ui/cn) package, a single function for conditional class joining and Tailwind conflict resolution, as an alternative to composing `clsx` with `tailwind-merge`. Its input type matches `cva`'s, so object and array authoring stay available. It's wired in via [`cva/core`](/beta/api-reference#cvacore) with `defineConfig({ cx: cn })` and re-exported as `cn`. See [Handling style conflicts](/beta/getting-started/installation#handling-style-conflicts) for the details.
